# Утилита для расчёта количества совершённых грехов (Вариант 13)

**Дисциплина:** Жизненный цикл разработки программного обеспечения
**Выполнил:** студент группы 450501Лесковский Е.Е.

## Описание проекта
Данный проект представляет собой приложение с графическим интерфейсом (GUI) на базе библиотеки Java Swing. Программа рассчитывает "количество совершённых грехов" пользователя на основе введённой даты рождения по специальному алгоритму:

количество прожитых дней делится по модулю на 666 (базовое значение), после чего к нему прибавляется утроенный порядковый номер дня недели даты рождения.

### Основные функции:
- Ввод даты рождения через отдельное модальное окно.
- Проверка корректности введённых данных (формат "дд.ММ.гггг", проверка на даты в будущем и ранее 1900 года).
- Сохранение и автоматическое восстановление последних введённых данных при повторном открытии диалога.
- Вывод результатов расчёта и сохраненной даты на главную форму.

### Архитектура:
Приложение спроектировано с использованием паттерна **MVC (Model-View-Controller) с активной моделью**.
- **Model (`src/model`)**: Хранит данные (дата рождения, результат расчёта) и реализует бизнес-логику. Выступает "Наблюдаемым" объектом, оповещая подписчиков об изменениях через `PropertyChangeSupport`.
- **View (`src/view`)**: Реализует графический интерфейс (Swing). Подписывается на уведомления модели (`PropertyChangeListener`) и автоматически перечитывает данные при её изменении.
- **Controller (`src/controller`)**: Обрабатывает действия пользователя от View (нажатия кнопок), производит валидацию через `DateValidator` и вызывает изменения в Model.
- **App (`src/app`)**: Точка входа в программу.
